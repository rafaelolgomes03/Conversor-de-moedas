# Conversor de Moedas 💱

Este é um programa simples desenvolvido em C# que converte valores em **Real (BRL)** para outras moedas internacionais.

## 🚀 Funcionalidades

O programa realiza a conversão de Real para as seguintes moedas:
* **Dólar Americano (USD)**
* **Euro (EUR)**
* **Peso Argentino (ARS)**

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Plataforma:** .NET
